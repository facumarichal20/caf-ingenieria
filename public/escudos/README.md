# Escudos de rivales

Colocá aquí los escudos originales como archivos PNG, JPEG, WebP, TIFF o AVIF, con el nombre del equipo (por ejemplo `ISEF.png` o `Odonto. Admin..png`).

Ejecutá `npm run escudos:optimizar` para generar los WebP cuadrados de 256 × 256 px con transparencia. Los nombres de salida se corresponden con `data/equipos.json`.
